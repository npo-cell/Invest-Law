# Documentation partagée

Tout ce qui est produit avec Claude (ou à la main) et doit être visible par toute l'équipe va ici.

| Dossier | Contenu |
|---|---|
| `notes/` | Notes de travail, idées, comptes rendus de réunion |
| `analyses/` | Recherches et analyses juridiques / financières |
| `livrables/` | Documents finaux (mémos, contrats, rapports) |
| `sessions/` | Résumé de chaque session Claude : objectif, décisions, liens vers artéfacts/docs |

Nommage : `AAAA-MM-JJ-sujet-court.md` (ex. `2026-10-12-statuts-sas.md`).
